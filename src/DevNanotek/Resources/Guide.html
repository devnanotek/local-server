1. What is DEVNANOTEK?

DEVNANOTEK is a free local server manager, similar to XAMPP and Laragon. It isn't tied to a closed bundle; it downloads every component from its official source:

ComponentSourceWhat it does
PHP (7.4 – 8.5)windows.php.netInstall several versions and switch with one click.
Apache 2.4apachelounge.comWeb server with .htaccess support (works like cPanel/Plesk).
Nginxnginx.orgOptional, lighter web server.
MariaDB / MySQLmariadb.org / mysql.comDatabase with a version of your choice.
PostgreSQL (optional)postgresql.org (EDB packages)A second database that runs alongside MariaDB/MySQL.
SQLitebuilt into PHPFile-based database; nothing to install.
SQL Server driver (optional)MicrosoftLets PHP connect to SQL Server.
phpMyAdminphpmyadmin.nethttp://localhost/phpmyadmin
Admineradminer.orgSingle-page manager for all databases: http://localhost/adminer
Mailpitgithub.com/axllent/mailpitTest mailbox that catches outgoing emails.
mkcertgithub.com/FiloSottile/mkcertLocal HTTPS certificate that your browser trusts.
Node.js, Composernodejs.org, getcomposer.orgReady to use in the terminal.

The key difference: Apache/Nginx, the database and Mailpit run as real Windows services. Your sites work even when the app window is closed. When the computer shuts down, Windows stops the services cleanly, and if a service crashes, Windows restarts it automatically.

2. First-time setup

  1. Double-click DevNanotek.exe. The app asks for administrator permission; it needs it to install services and edit the hosts file.
  2. The app copies itself to C:\devnanotek\app and adds shortcuts to the Desktop and the Start menu. Use those shortcuts from now on; you can delete the exe you downloaded.
  3. The Setup wizard opens. The top shows your Windows version and architecture (64-bit / 32-bit / ARM64); the right files are chosen automatically. Choose the PHP version, the web server (Apache is recommended), the database, the tools and the run mode, then click Install and start. You can switch the language in the top right corner of the wizard.
  4. The components are downloaded and installed (about 200 MB). When it's done, click Open localhost to open http://localhost.
If you skipped the wizard, you can reopen it at any time with Versions → Setup wizard.
If XAMPP, Laragon or WAMP is running, close it first. They use the same ports (80, 443, 3306). The wizard warns you if it finds a conflict.
Smart App Control: when this Windows 11 feature is on, it blocks unsigned or newly released programs — including Apache's DLLs, Mailpit, Nginx and DevNanotek.exe itself. It's the most common reason XAMPP and Laragon "break on their own". DEVNANOTEK detects it and shows a warning on the Overview page. See section 19 for details.

3. Interface, language, light / dark mode

The left menu has six pages: Overview, Projects, Versions, Settings, Logs and Help. The box at the bottom left shows the service status with colored dots; click it to open the tray status window.

Language (Türkçe / English)

On first launch the app follows the Windows display language: Turkish if Windows is in Turkish, English for any other language. You can change it at any time in Settings → General → Language / Dil; the same choice is in the top right corner of the setup wizard. The options are Device language (follows Windows), Türkçe and English.

When you change the language, the app closes and reopens in the new language; your services keep running. Notifications, log entries, command-line output, the http://localhost start page and this guide follow the chosen language too (Turkish guide: docs\Kilavuz.html).

Light / dark mode

The theme button at the bottom left (screen / sun / moon icon) cycles through System → Light → Dark. The same choice is in Settings → General → Appearance. With "System" selected, the app follows the Windows light/dark setting and switches automatically when the Windows theme changes. The window title bar follows the theme too.

Explanations and notifications

  • To keep the screen clean, explanations sit behind the ? icons. Hover over one to see the explanation.
  • Results appear as colored notifications in the bottom right: green for success, yellow for warnings, red for errors. Notifications with more information have a Details link.
  • Long operations (installation, repair) show their progress log in the same colors.

Navicat / HeidiSQL / DBeaver

Create a new MySQL connection: host 127.0.0.1, port 3306, user root, empty password. MariaDB works with the "MySQL" connection type too.

Connecting from PHP

$pdo = new PDO('mysql:host=127.0.0.1;port=3306;dbname=mydatabase;charset=utf8mb4', 'root', '', [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,

Changing versions and moving data

Each database branch has its own data folder (for example data\mariadb-11.4). Patch updates within the same branch (11.4.13 → 11.4.14) use the same data. When you switch to another branch (such as 11.4 → 11.8), the old data doesn't show up in the new version automatically, but it isn't deleted either. To move it:

  1. While the old version is active, use Settings → Database → Back up.
  2. On Versions → Database, install the new version and click Activate.
  3. Use Settings → Database → Restore from backup.

For extra MySQL settings (e.g. sql_mode, lower_case_table_names), use Settings → Database → Extra settings (custom.cnf). This file is never overwritten.

PostgreSQL

PostgreSQL is optional and runs alongside MariaDB/MySQL (a separate service on port 5432). To install it, choose a version under Versions → Database → PostgreSQL and click Install; you can also pick it in the setup wizard. Versions 14–18 are available. The RECOMMENDED one is the major version before the newest.

  • When it's installed, PHP's pgsql and pdo_pgsql extensions are turned on automatically.
  • psql, pg_dump and createdb are ready in the terminal.
  • There is one data folder per major version (data\postgresql-17); data is kept across patch updates.
  • Under Settings → Database → PostgreSQL you can create databases, back up (pg_dumpall) and restore. Put your own settings in custom.conf.

SQLite

SQLite is file-based and needs no server. PHP's pdo_sqlite and sqlite3 extensions are on by default:

$pdo = new PDO('sqlite:' . __DIR__ . '/data.sqlite');

You can open .sqlite files with Adminer: choose "SQLite" as the system on the sign-in screen and type the file's full path.

SQL Server

To let PHP connect to Microsoft SQL Server, click Versions → Tools → SQL Server driver → Install. The installation:

  • adds the sqlsrv and pdo_sqlsrv extensions to every installed PHP version (8.1 and later) and turns them on;
  • installs Microsoft ODBC Driver 18 too, if you accept Microsoft's license.

SQL Server itself is not installed; you connect to an existing server (Docker, a remote server or SQL Server Express):

$pdo = new PDO('sqlsrv:Server=127.0.0.1,1433;Database=test;TrustServerCertificate=1', 'sa', 'password');

Adminer — all databases in one place

http://localhost/adminer manages MySQL/MariaDB, PostgreSQL, SQLite and SQL Server. For local use it allows sign-in without a password, and it's reachable from this computer only. The Adminer button on the Overview page and the links on the start page take you straight into the right database. phpMyAdmin keeps working as before.

7. PHP

Changing versions

Install the versions you want on Versions → PHP by clicking Install. Choose the active version from the list under Overview → Active versions and click Switch, or use Activate on the Versions page. For a version that isn't listed (e.g. 8.2.12), type the number in the field at the top and click Add and install.

Use the same PHP version locally as your hosting does. Version differences cause most surprise errors.

Extensions: gd, zip, intl… (quick access)

You can turn the extensions projects often need on or off in two places:

  • Overview → Active versions → Extensions (gd, zip…): a small window opens. Flip the switches and click Save and apply.
  • Settings → PHP → Quick settings → Common extensions: saved together with the php.ini values.

The list includes gd, zip, intl, mbstring, curl, openssl, fileinfo, exif, soap, sodium, mysqli, pdo_mysql, pdo_pgsql, pgsql, pdo_sqlite, sqlite3, gmp, xsl, ftp, sockets, ldap, bz2, gettext, tidy and opcache. The ? icon explains what each one does. The web server restarts by itself. If an extension fails to load, you get a warning and that extension is turned off. The common ones (gd, zip, intl, mbstring, curl…) are already on by default.

php.ini settings

The Settings → PHP tab has three sections:

  • Quick settings: switches for common extensions and values such as memory_limit, upload_max_filesize, post_max_size, max_execution_time, display_errors and date.timezone. The Development defaults button resets them to the recommended values.
  • Extensions: tick intl, gd, zip, mysqli, pdo_mysql, curl, soap, sodium and others to turn them on or off.
  • php.ini: edit the whole file. A php.ini.bak backup is taken before every save.

When you save, the web server restarts by itself. If PHP reports warnings at startup, the app tells you. Each PHP version has its own php.ini.

The defaults suit development: 512M memory and upload limit, 300 s execution time, errors shown on the page, time zone Europe/Istanbul (change it under Quick settings), OPcache on.

Terminal, Composer and PHP commands

Overview → Terminal, or the Terminal button on the Projects page, opens a command prompt set up with the active versions:

php -v
composer install
composer create-project laravel/laravel blog
node -v && npm install
mysql -u root
mysqldump -u root mydatabase > backup.sql

If "Make php, composer, node and mysql work in every terminal (PATH)" is on, these commands work in every terminal (including the VS Code terminal, in newly opened windows).

8. Apache / Nginx

Apache is recommended. Like cPanel and Plesk servers, it reads .htaccess files and has mod_rewrite on. If you choose Nginx, PHP runs through a php-cgi pool (FastCGI) and .htaccess files are not read.

Make the choice under Settings → General → Web server and document root and click Save and apply.

Your own rules (custom.conf)

httpd.conf and nginx.conf are generated automatically; don't edit them by hand. Put your own additions in the custom.conf file on the Settings → Web server tab and click Test, save, apply. The configuration is tested before saving. If there's an error, the change is rolled back automatically, so the server keeps working.

# Apache custom.conf example: serve a Node app under /app (including socket.io)
ProxyPass        "/app/socket.io/" "ws://127.0.0.1:3000/socket.io/"
ProxyPass        "/app/"           "http://127.0.0.1:3000/"
ProxyPassReverse "/app/"           "http://127.0.0.1:3000/"

9. HTTPS and domains

HTTPS

If mkcert is installed, https://localhost opens in the browser without warnings. DEVNANOTEK creates a local root certificate and adds it to the Windows trusted certificates. The certificate is valid only on your computer. Chrome and Edge pick it up right away; you may need to restart Firefox once.

PHP's curl/openssl settings trust this certificate as well, so calls to https://project.test from PHP don't fail verification.

Domain (project.test)

To open a project by its own domain, select the folder on the Projects page. Type project1.test in the Domain (virtual host) box and click Create. The hosts file, the web server and the SSL certificate are updated automatically. The project now opens at http://project1.test and https://project1.test.

If the folder has public\index.php and no index file at its root (Laravel, Symfony), the document root becomes public automatically.

If you turn on Settings → SSL and domains → Create a domain for each top-level folder, every top-level folder in httpdocs automatically becomes foldername.test.

Use the .test suffix. Browsers force .dev and .app to HTTPS, and .local can cause slowdowns on the network.

11. Node.js and socket.io

Node.js, npm and npx are ready in the terminal. You can install several Node versions and switch between them on the Overview page. The switch applies to newly opened terminals.

cd C:\devnanotek\httpdocs\GITHUB\chat

12. New versions and updates

DEVNANOTEK checks the official sources for new versions of PHP, MariaDB, MySQL, Node.js, Apache, Nginx, phpMyAdmin and the other tools automatically every 12 hours. To check right away, click Versions → Check now. The top of the page shows when the last check ran and your computer's architecture.

The RECOMMENDED badge

One version of each component is marked RECOMMENDED. The choice is based on hosting compatibility and stability:

ComponentRecommended
PHPThe branch before the newest (the most common on hosting, with mature extensions). E.g. 8.4 once 8.5 is out.
MariaDB / MySQLThe newest long-term support (LTS) version.
Node.jsThe newest LTS version.
NginxThe stable branch.

Only the newest patch of each branch is listed, so the list stays short. You can install any version and switch with Activate; you don't have to use the recommended one.

Updates

When a new patch is released in the same branch as an installed component (e.g. PHP 8.3.30 → 8.3.35):

  • An orange number appears next to Versions in the left menu and the tray icon shows a short notification.
  • On the card at the top of the Versions page, click Update (one at a time) or Update all.
  • The update installs the new version, carries over your php.ini settings, switches the active version and restarts the services. For MariaDB, the tables are upgraded with mariadb-upgrade; MySQL does this itself on first start. The data stays in the same folder. If everything succeeds, the old patch is removed.
Major version changes (such as PHP 8.3 → 8.4 or MariaDB 11.4 → 11.8) are never done automatically; since they can break your projects, you decide when to switch.

Updating DEVNANOTEK itself

The app is open source and new releases are published on GitHub Releases. It checks for a new version at startup and every 6 hours. When a new version is out:

  • The tray icon shows a notification once, and a card describing what's new appears at the top of the Versions page.
  • Click Update now. The new DevNanotek.exe is downloaded to your Downloads folder and its version is verified.
  • The app closes, the new version opens and installs itself into C:\devnanotek\app.

Your services, projects and settings stay as they are. To update by hand, download the new exe from the project site (devnanotek.github.io/local-server) and run it. The Help page shows which version you have.

15. Security and local network access

By default the web server is reachable from this computer only (127.0.0.1 and ::1). This means:

  • On shared networks such as cafés and hotels, nobody else can reach your sites or phpMyAdmin.
  • Windows Firewall doesn't ask "allow access?", and no firewall rule is added.

Testing from a phone or another computer

Tick Settings → General → Access from the local network and click Save and apply. Devices on the same network can then reach your sites at http://THIS-COMPUTERS-IP. A firewall rule is added for Private (home/work) networks only; access stays closed on public networks. Untick the box when you're done; the rule is removed too.

Database access from the network is a separate setting: Settings → Database → Database access from devices on the network. If you turn it on, be sure to set a root password.

phpMyAdmin is always reachable from this computer only.

16. Speed: why is phpMyAdmin slow the first time?

It isn't a fault. phpMyAdmin consists of thousands of PHP files. On first load, two things happen:

  1. PHP compiles these files and stores them in OPcache. Later loads come from the cache.
  2. Windows Defender scans each file the first time it's read.

DEVNANOTEK eases this in two ways:

  • After the services start, localhost and phpMyAdmin are opened once in the background to warm them up, so the cache is ready when you open them.
  • Optionally, Settings → System → Speed → Exclude from Defender scanning takes the C:\devnanotek folder out of scanning. This speeds up the first load noticeably. It's a security trade-off: only put code you trust in this folder. The exclusion is removed when DEVNANOTEK is uninstalled.

Example measurement: phpMyAdmin first load ≈ 0.5 s, later loads ≈ 0.25 s; localhost ≈ 0.06 s.

17. Using it on other computers, 32 / 64-bit

DevNanotek.exe is a single file. Copy it to another computer and run it to set up the same environment. The app detects the Windows version and processor architecture by itself and downloads the right files:

ComputerComponents downloadedNote
64-bit Windows 10 / 11x64All components are available. Recommended.
ARM64 Windows 11x64 (through Windows emulation)All components are available.
ARM64 Windows 10x86 (32-bit)The limits in the 32-bit row apply.
32-bit Windows 10x86PHP, Apache, Nginx, Node.js (22 and earlier), phpMyAdmin and Composer are installed. MariaDB, MySQL, PostgreSQL, Mailpit and mkcert are no longer published for 32-bit Windows, so they can't be installed; the wizard says so clearly.

Requirements:

  • Windows 10 or Windows 11. The .NET Framework 4.8 the app needs comes with these versions. On Windows 7 / 8.1 the app may open, but current PHP, Apache and database versions may not work; the wizard warns you.
  • An administrator account. The app asks for permission when it opens.

  • Ports 80, 443 and 3306 must not be used by another program (IIS, XAMPP, Laragon, Skype…). If they are, change them in Settings → General → Ports.

If the Visual C++ Runtime is missing or outdated, the wizard installs it too (for the right architecture).

18. Moving to hosting (Plesk / cPanel / VPS)

Linux compatibility check

Before uploading your project to the server, select the folder on the Projects page and click Linux compatibility → Check. The app scans the files without changing them and lists the problems line by line, in color:

CheckWhy it matters
Letter-case mismatch (require 'Config.php', <img src="Logo.PNG">)Works on Windows, but on Linux it gives "file not found" / 404.
Backslashes in paths (lib\db.php) and C:\ pathsOn Linux the folder separator is / and there's no C: drive.
Class name and file name with different letter case (class UserModel → userModel.php)Composer's autoloader can't find the class on Linux.
.sh scripts with CRLF line endings, Windows commands (exec('dir')), COM objectsThey don't work on Linux.
Mixed-case table names (SELECT * FROM Users)MySQL table names are case-sensitive on Linux.
php_value / php_flag in .htaccessError 500 if the server uses PHP-FPM; use .user.ini instead.
File names with non-ASCII characters, PHP files with a BOMCorrupted names in FTP transfers and "headers already sent" errors.

Each line explains how to fix it. Double-click a line to open the file at that line in VS Code. You can copy or save the report. vendor and node_modules are not scanned.

General rules

  • Letter case: Windows doesn't distinguish upper and lower case in file names; Linux does. require 'Config.php' with config.php works locally but fails on the server. Write file names consistently.
  • Table names: on Linux, MySQL table names are case-sensitive too. In queries, write table names exactly as you created them.
  • Matching versions: use the same PHP and MariaDB/MySQL versions locally as on the server. Plesk and cPanel usually have MariaDB 10.6/10.11/11.4 or MySQL 8.0/8.4.
  • Exporting: phpMyAdmin → Export, or mysqldump -u root mydatabase > backup.sql. Import on the server with phpMyAdmin or mysql.
  • Character set: use utf8mb4 both locally and on the server.
  • Paths: use __DIR__ instead of absolute paths like C:\....
  • .htaccess: since you use Apache locally, .htaccess rules that work locally work the same way on cPanel/Plesk (Apache or LiteSpeed).

19. Troubleshooting

"An Application Control policy has blocked this file" / services never start

This is Windows 11's Smart App Control. It won't run programs that lack a digital signature or that Microsoft doesn't recognize yet; for example, new releases of Apache Lounge, Mailpit and Nginx are unsigned. To see its state, run this in PowerShell:

Get-MpComputerStatus | Select-Object SmartAppControlState

If the value is On, local server software (DEVNANOTEK, XAMPP, Laragon, some parts of Docker) can't run reliably. To turn it off: Settings → Privacy & security → Windows Security → App & browser control → Smart App Control settings → Off.

This is a security feature; the decision is yours. Depending on the Windows version, turning it back on later may require resetting Windows. The Windows Defender antivirus does not turn off; it keeps running. On computers used for software development this feature is usually kept off.

Apache doesn't start / "port 80 is in use"

Check Settings → System → Port check first. Common causes:

  • System (PID 4): IIS or the "World Wide Web Publishing Service" is running. Stop it in the Services console and set it to "Disabled".
  • httpd.exe / mysqld.exe: XAMPP or Laragon is running. Close it and turn off its autostart.
  • Skype, VMware or Docker: free the port in that program's settings.
  • Or change the HTTP port to 8080 in Settings → General → Ports. The address then becomes http://localhost:8080.

The database doesn't start

Check the Logs → Database — errors log. Usually port 3306 is used by another MySQL, or there's an invalid line in custom.cnf. The log icon next to the service on the Overview page opens the right log directly.

"VCRUNTIME140.dll not found" or Apache/PHP won't open

Versions → Tools → Visual C++ Runtime → Install.

Antivirus

Some antivirus programs block changes to the hosts file or new services. Add the C:\devnanotek folder to the exclusions (for Windows Defender, see section 16).

Fix everything

Start with Repair / Reset → Quick repair; if that doesn't solve it, try Full repair (section 14).

20. Command line

In a command prompt opened as administrator (the output follows the app language):

"C:\devnanotek\app\DevNanotek.exe" --status          :: service status
"C:\devnanotek\app\DevNanotek.exe" --start-all       :: start all
"C:\devnanotek\app\DevNanotek.exe" --stop-all        :: stop all
"C:\devnanotek\app\DevNanotek.exe" --apply           :: apply the configuration
"C:\devnanotek\app\DevNanotek.exe" --check-updates   :: check for new versions, list the recommended ones
"C:\devnanotek\app\DevNanotek.exe" --mode manual     :: run mode: always | manual
"C:\devnanotek\app\DevNanotek.exe" --install php mariadb node   :: install the recommended versions
"C:\devnanotek\app\DevNanotek.exe" --install php:8.3.30         :: install a specific version
"C:\devnanotek\app\DevNanotek.exe" --install postgresql adminer :: add PostgreSQL and Adminer
"C:\devnanotek\app\DevNanotek.exe" --linux-check C:\devnanotek\httpdocs\GITHUB\project1   :: Linux compatibility report

21. Uninstalling

DEVNANOTEK appears in the Windows Control Panel → Programs and Features list (and in Settings → Apps) as "DEVNANOTEK Local Server".

  • Uninstall: opens DEVNANOTEK's uninstall window.
  • Change: opens the Repair and Reset window (section 14).

The same uninstall window opens from inside the app with Settings → System → Uninstall DEVNANOTEK…. There are two options:

OptionDeletedKept
Uninstall the app, keep my projects and databases (recommended)Services, hosts entries, PATH entries, autostart, SSL certificate, firewall rules, Defender exclusion, tray icon entry, shortcuts, the Control Panel entry, programs (PHP, Apache, MariaDB…), settings files, logs and DevNanotek.exehttpdocs (projects), data (databases), backups. If you install it again, you pick up where you left off.
Delete everythingAll of the above plus the entire C:\devnanotek folder (including projects and databases). Optionally, a .sql backup of all databases is saved to the Desktop first.Only the backup you saved to the Desktop.

If you start the uninstall while the app is open, the running DEVNANOTEK closes itself first. A few seconds after you close the window, the remaining files are deleted too.

22. The icon next to the clock (tray)

While DEVNANOTEK is running, an orange D logo appears next to the clock in the bottom right of the screen. The dot in the corner of the logo shows the overall status:

DotMeaning
GreenAll services are running.
YellowOne or more services are stopped or starting.
RedA service stopped with an error, or a component isn't installed.
  • Single click: a small status window opens. The services are listed with colored dots, versions and states; the active PHP, web server, database, Node.js, phpMyAdmin and Mailpit versions are shown. You can start and stop each service, and use "Start all / Stop all", localhost, phpMyAdmin and httpdocs shortcuts.
  • Double click: the main app window opens.
  • Right click: the menu (Show, Start all / Stop all, Repair / Reset, Exit…).

If you don't see the icon, click the ^ arrow on the taskbar. Drag the icon from there onto the taskbar to keep it always visible.

The same colored service list and the active versions are always visible at the bottom of the app's left menu and on the Overview page.

23. Linux version

You can set up the same environment on a Linux computer too. The quickest way is to open a terminal as your normal user on Linux and run this command. It downloads the latest version of the script from GitHub and installs it:

curl -fsSLO https://github.com/devnanotek/local-server/releases/latest/download/devnanotek.sh && sudo bash devnanotek.sh install

If you'd rather not download it from the internet, click Help → Get the Linux version. The devnanotek.sh and KURULUM.md files are extracted to the C:\devnanotek\docs\linux folder. Copy the file to the Linux computer and run:

sudo bash devnanotek.sh install
SupportedDetails
Ubuntu 22.04 / 24.04 / 26.04, Debian 11–13, Linux Mint, Pop!_OS, ZorinMultiple PHP versions: ppa:ondrej/php or packages.sury.org
AlmaLinux, Rocky, RHEL, CentOS Stream, Oracle, CloudLinux (8–10), FedoraMultiple PHP versions: Remi repository · SELinux is configured automatically

The setup wizard asks for: PHP version, Apache or Nginx, MariaDB or MySQL, PostgreSQL, Node.js, Mailpit, phpMyAdmin, Adminer, Composer, local HTTPS and the run mode. After installation the devnanotek command opens the menu. Common commands:

devnanotek status                       # services: green / yellow / red
sudo devnanotek php 8.3                 # install and switch PHP version
sudo devnanotek ext enable gd           # turn on an extension
sudo devnanotek ini memory_limit 1G     # php.ini setting
sudo devnanotek vhost add project1.test GITHUB/project1
sudo devnanotek db backup               # database backup
sudo devnanotek mode manual             # only when I start it
sudo devnanotek uninstall               # uninstall (projects are kept)

Projects live in the /opt/devnanotek/httpdocs folder (a ~/httpdocs shortcut is also created in your home folder) and open at http://localhost/folder. PHP runs as your user, so you don't have to deal with file permissions. On Linux, table names are case-sensitive, just like on the server. The Linux script's own messages are in Turkish; see KURULUM.md for details.
